## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for this repository, using the `gh` CLI. See `../../docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five-label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `../../docs/agents/triage-labels.md`.

### Domain docs

This directory is backend-focused (`apps/api`) in a multi-context monorepo. Prioritize backend requirements and contracts from `docs/PRD.md`, then read shared and backend ADR/context docs as they exist. See `../../docs/agents/domain.md`.
