## Recommended next actions when a failure is found

1. Reproduce the failing step exactly from the smoke-test guide.
2. Decide whether it is:
   - contract mismatch
   - backend logic bug
   - FE mapping/state bug
3. Add or update the narrowest failing automated test possible before fixing.
4. Fix only that slice.
5. Re-run the exact smoke-test step plus the related API test.
