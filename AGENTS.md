## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for this repository, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five-label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

This repo is multi-context; use `CONTEXT-MAP.md` to locate context docs, then read context-specific and shared ADRs. For backend work, prioritize the `apps/api` context. See `docs/agents/domain.md`.
